# Minificação e motores

## Propósito

Este documento definirá os contratos dos motores, os critérios de homologação e o comportamento autorizado para a minificação de JavaScript e CSS.

## Escopo atual

Os requisitos autoritativos serão consolidados na próxima tarefa de especificação. O esbuild é apenas o primeiro motor planejado para homologação; nenhuma integração está implementada.
